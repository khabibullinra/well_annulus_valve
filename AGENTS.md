# well_annulus_valve

HTML-приложение для расчёта работы добывающей нефтяной скважины с УЭЦН и газлифтным
клапаном перепуска газа из затрубного (межтрубного) пространства в НКТ.

Цель: исследовать возможность работы скважины с **закрытой затрубной задвижкой** —
весь газ, сепарируемый на приёме насоса, уходит через газлифтный клапан в НКТ,
давление в затрубе устанавливается равновесием клапана (не выше заданного предела).
Если равновесие недостижимо — показать, сколько газа придётся вентилировать через
затрубную задвижку при максимально возможном затрубном давлении.

Язык проекта: **TypeScript** (расчётное ядро) → сборка esbuild → одиночный
`index.html` + bundle.js. Тесты: **vitest**. UI на русском.

## Физическая модель

Вертикальная скважина, глубина перфораций `H_perf`, насос на `H_esp`.

**Температура**: геотерма `T(z) = 5 + 3·z/100 °C` (упрощение по требованию).

**IPR (Вогель, композитный как в unfpy)**: пластовое давление `p_res`, тестовая
точка `(q_test, p_test)`, `pb` (по умолчанию = p_res). Выше pb — Дарси, ниже —
Вогель; вода — параллельная линейная ветвь. См. `src/core/ipr.ts`.

**PVT blackoil (Standing-набор с калибровкой, как в unfpy Feed)**:
- Standing pb/Rs (взаимообратные, с линейной усадкой pb при rsb<1.8), Bo Standing,
  Beggs-Robinson вязкость (dead/sat), Vasquez-Beggs co и недонасыщенная вязкость,
  Z-фактор (Brill-Beggs / Dranchuk-ABK / Kareem), Lee вязкость газа, McCain вода
  (Bw, вязкость, плотность), Baker-Sverdloff поверхностное натяжение.
- Калибровочные факторы `p_fact/b_fact/mu_fact` по пользовательским pb, bob, mu_ob
  при пластовой температуре (как в `feed_calc_Standing`).
- Юниты: давление atma, температура °C, расходы sm3/сут, GOR м3/м3, вязкость сП.
  Внутри ядер — МПа и K (T_K_ZERO_C = 273.0, стандартные условия 1 atma / 20 °C,
  RHO_AIR = 1.2217 — как в unfpy/core/constants.py).

**Поток ниже насоса** (перфорации → приём): восходящий drift-flux в открытом
стволе обсадной колонны (без хвостовика), полный GOR флюида.

**Drift-flux (sand_transport)**: режимы пузырьковый/снарядный/churn/кольцевой по α
и vsg (двухшаговая классификация), замыкания:
- пузырьковый: C0 = 1.20, vd = 1.53·[gσΔρ/ρl²]^0.25 (Harmathy)
- снарядный: C0 = 1.15, vd = 0.35·√(gDΔρ/ρl)
- churn: C0 = 1.08, vd = 0.22·√(gDΔρ/ρl); кольцевой: C0 = 1.00, vd = 0.04·√(...)
- `alpha = vsg/(C0·vm + vd)`, clamp 0..0.95; градиент = гидростатика (α-взвешенная
  плотность) + Дарси-Вейсбах (Colebrook гладкая: f=(0.79·lnRe−1.64)^−2, ламинар 64/Re),
  без ускорения. Марш по сегментам, явный Эйлер.

**Барботаж в затрубе** (неподвижная жидкость): тот же drift-flux при vsl = 0 —
`alpha_ann = vsg/(C0·vsg + vd)` с пузырьковым замыканием (Harmathy). Поток газа
ниже клапана = весь сепарированный, выше клапана = сепарированный минус ушедший в
клапан. Колонна: газовая шапка сверху (P_затр) + пузырьковая жидкость до уровня;
уровень находится из согласования давления на приёме (бисекция по глубине уровня).
Если уровень достигает приёма — газ в приём насоса (аварийный признак).

**Сепарация на приёме**: постоянный коэффициент ksep. Модификация флюида после
сепарации — как `feed_mod_after_separation` (unfpy): рабочий GOR на насос
`rp_new = rs + (rp − rs)·(1 − ksep)`; свободный газ в насос ×(1 − ksep); при
`rp_new < rsb` — пересчёт калибровки pb/bob/muob интерполяцией по таблицам.
Сепарированный газ уходит в затруб.

**ЭЦН (unfpy)**: кривые head/power/eff vs rate из `src/data/pumps.json` (43 насоса
БД unfpy), полиномиальная интерполяция deg-2, affinity laws по частоте, вязкостная
поправка (SPE/гамма-метод), деградация от свободного газа — квадратичные модели
1–4 по газосодержанию на приёме (пересчёт по ступеням), мощность × ρсмеси/1000,
по ступеням с пересчётом PVT (T фикс. геотерма). Мощность электрическая = мощность
на валу / КПД двигателя.

**Газлифтный клапан**: глубина `H_valve`, диаметр отверстия `d_orifice`, Cd
задаваемый (по умолчанию 0.85), встроенный обратный клапан — только затруб → НКТ,
только газ. Сжимаемый дроссель: критический/докритический режим через отношение
давлений с показателем адиабаты k (расход в sm3/сут по P, T, Z вверх по потоку).

**Граничные условия**: буферное давление — жёсткое (НКТ от устья). Затрубное —
ограничение сверху `P_cas_max`; расчётное может быть меньше, если возможно закрытие
задвижки.

## Решатель (src/core/well.ts)

1. Бисекция по `pwf` → согласование буферного давления (как WellESP.calc_from_pwh).
   Внутри: IPR → q_liq; марш ниже насоса (drift-flux, обсадная) → p_приёма; ksep +
   модификация флюида; ЭЦН по ступеням → p_выкида; марш по НКТ вверх → p_буф.
2. Внутренняя неподвижная точка по `q_valve`: расход через клапан влияет на
   газосодержание НКТ выше клапана → P_НКТ(H_valve) → расход через клапан.
3. Внешняя бисекция по `P_cas*` для равновесия закрытой задвижки: q_valve = q_sep.
   Если требуемое P_cas* > P_cas_max — невозможно: P_cas = P_cas_max, клапан
   пропускает сколько может, остаток вентилируется (q_vent = q_sep − q_valve).

**Сценарии сравнения**:
- А: без клапана, затрубная задвижка открыта — весь сепарированный газ
  вентилируется при P_cas = P_cas_max.
- Б: без клапана, задвижка закрыта — газ накапливается, уровень опускается к приёму,
  газ в насос (деградация/срыв). Показывает, зачем нужен клапан.
- В: с клапаном (параметры d, H_valve) — основной расчёт.

**Оптимизация** (автоматический режим): перебор (H_valve × d_orifice) в Web Worker;
смотрим за обоими показателями: максимум q_нефти и минимум удельной энергии
(кВт·ч/м3), при условии возможности закрытия задвижки; против базы А.

## Конвенции

- Ядро — чистые функции/классы без DOM; только core импортируется тестами и worker'ом.
- Все расчётные функции принимают/возвращают данные в единицах atma/°C/sm3 сут/м/сП
  (суффиксы в именах полей), внутренние ядра конвертируют в МПа/K сами.
- Комментарии: только нетривиальные места и ссылки на источники формул.
- Каждый wave — отдельный коммит(ы) с осмысленным сообщением.
- Новая физика = сначала тест против эталона/sanity, потом код.
