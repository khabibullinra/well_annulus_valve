# well_annulus_valve

**Онлайн-версия приложения**: <https://khabibullinra.github.io/well_annulus_valve/>
(ветка `pages`, ничего устанавливать не нужно — всё считается в браузере).

Расчёт работы добывающей нефтяной скважины, оснащённой УЭЦН и газлифтным клапаном
перепуска газа из затрубного (межтрубного) пространства в НКТ.

**Исследовательский вопрос**: можно ли работать скважиной с **закрытой затрубной
задвижкой** — так, чтобы весь газ, сепарируемый на приёме насоса, уходил через
газлифтный клапан обратно в НКТ, а давление в затрубе устанавливалось равновесием
клапана (не выше заданного предела)? Если да — газ не вентилируется в атмосферу,
а если клапан не справляется — приложение показывает, сколько газа придётся
вентилировать через затрубную задвижку при максимально возможном затрубном давлении.

## Что делает приложение

- Считает согласованную рабочую точку «пласт — скважина — ЭЦН» при жёстком буферном
  давлении: приток по Вогелю, многофазный поток drift-flux по стволу, ступенчатый
  расчёт насоса с деградацией от свободного газа, сепарация на приёме.
- Строит распределения давления раздельно в НКТ и в затрубе: линия затруба состоит
  из газовой шапки (барометрическая формула) и барботажа газа через столб
  неподвижной жидкости до динамического уровня.
- Подбирает равновесие газлифтного клапана (дроссель с обратным клапаном) и
  показывает, достижимо ли закрытие затрубной задвижки, либо сколько газа придётся
  вентилировать при предельном затрубном давлении.
- Рисует узловой анализ (IPR + две кривые подъёма: с клапаном и без), каталожные
  характеристики ЭЦН на трёх осях (пунктир — номинал по воде, сплошная — расчёт
  со скважинными поправками), потребление энергии от дебита и дельты «клапан − база»
  по нефти (т/сут) и энергии (кВт·ч/сут).
- Ищет оптимальные параметры клапана перебором сетки «глубина × диаметр отверстия»
  по двум критериям: максимум добычи нефти и минимум удельной энергии.

## Источники моделей

Проект опирается на два открытых репозитория:

- **[unfpy](https://gitverse.ru/khabibullinra/unfpy)** — Python-порт uniflocVBA 7.58.
  Взяты формулы и структура: PVT-корреляции Стоунда с калибровкой по пользовательским
  Pнас/Bo/μob, Beggs-Robinson, Vasquez-Beggs, Z-факторы (Kareem/DAK/Brill-Beggs),
  Lee, McCain (вода), модификация флюида после сепарации
  (`feed_mod_after_separation`), модель ЭЦН (полиномиальные кривые, affinity laws,
  вязкостная коррекция SPE, квадратичные модели деградации от свободного газа),
  композитный IPR Вогеля, узловое согласование бисекцией. Каталог из 43 реальных
  насосов ЭЦН перенесён из БД unfpy (`unfpy/data/esp_db.json`); эталонные JSON из
  `unfpy/tests/reference/pvt_correlations` используются как паритет-тесты.
- **[sand_transport](https://gitverse.ru/khabibullinra/sand_transport)** —
  drift-flux модель многофазного потока: Zuber–Findlay в явной форме
  α = vsg/(C0·vm + vd), режимы пузырьковый/снарядный/churn/кольцевой с замыканиями
  Harmathy/Тейлора, гидростатика + трение Дарси-Вейсбаха, явный Эйлер по сегментам.
  Барботаж газа в затрубе реализован тем же замыканием при нулевой скорости
  жидкости (vsl = 0).

Сборка из исходников: `npm install && npm test && npm run build`.

## Физическая модель

| Блок | Модель | Источник формул |
|---|---|---|
| PVT blackoil | Standing pb/Rs/Bo с калибровкой по pb, bob, muob пользователя; Beggs-Robinson вязкость; Vasquez-Beggs co; Z-фактор Kareem/DAK/Brill-Beggs; Lee вязкость газа; McCain вода; Baker-Sverdloff натяжение | `unfpy/pvt/correlations/*`, `feed_njit.py` |
| Приток | IPR Вогеля (композитная: Дарси выше pb + Вогель ниже), вода — параллельная линейная ветвь, калибровка по тестовой точке | `unfpy/reservoir/ipr.py` |
| Поток ниже насоса (перфорации → приём) | drift-flux, восходящий, открытый ствол обсадной колонны | `sand_transport` |
| НКТ выше насоса | drift-flux с газом насоса (+ газ клапана выше глубины клапана) | `sand_transport` |
| Затруб | неподвижная жидкость + барботаж газа (drift-flux при vsl=0, замыкание Harmathy); газовая шапка и уровень жидкости из согласования давления на приёме | собственная модель на замыканиях sand_transport |
| Сепарация на приёме | постоянный коэффициент ksep + модификация флюида (рабочий ГФ, свободный газ, пересчёт калибровки pb/bob/muob) | `unfpy/pvt/model.py::feed_mod_after_separation` |
| ЭЦН | кривые напора/мощности/КПД 43 реальных насосов (полином deg-2, affinity laws по частоте), вязкостная коррекция SPE, деградация от свободного газа (квадратичные модели 0–4, пересчёт по ступеням), мощность × ρсмеси | `unfpy/esp/pump*.py` |
| Газлифтный клапан | сжимаемый дроссель (докритический/критический), Cd задаваемый, обратный клапан — только затруб → НКТ, только газ | классическое уравнение отверстия |
| Температура | геотерма T(z) = T_устья + градиент·z (упрощение) | — |

Drift-flux: явная формула `α = vsg/(C0·vm + vd)`, режимы пузырьковый/снарядный/
churn/кольцевой с замыканиями C0 = 1.20/1.15/1.08/1.00 и скоростями дрейфа
(Harmathy; 0.35/0.22/0.04·√(gDΔρ/ρl)). Градиент давления: гидростатика
α-взвешенной плотности + трение Дарси-Вейсбаха (Colebrook, гладкая труба).

## Решатель

1. **Бисекция по Рзаб** → согласование буферного давления (жёсткое ГУ).
   Внутри: IPR → марш ниже насоса → сепарация → ЭЦН по ступеням → марш по НКТ.
2. **Неподвижная точка по расходу клапана**: расход через клапан меняет
   газосодержание НКТ выше клапана → давление в НКТ на клапане → расход.
3. **Равновесие закрытой задвижки**: бисекция по P_затр до условия
   `q_клапана = q_сепарированного`. Если требуемое P_затр > P_max — закрытие
   невозможно, показывается объём вентиляции.

Сценарии сравнения:
- **А** — без клапана, задвижка открыта: весь газ вентилируется при P_затр = P_max;
- **Б** — без клапана, задвижка закрыта: весь свободный газ проходит через насос
  (деградация/срыв — показывает, зачем нужен клапан);
- **В** — с клапаном: основной расчёт.

Автоматический поиск: перебор сетки (глубина клапана × диаметр отверстия) с
рейтингом по двум показателям — максимум дебита нефти и минимум удельной энергии
(кВт·ч/м3) при условии возможности закрытия задвижки.

## Структура

```
src/core/    расчётное ядро (чистые функции, без DOM): units, pvt, feed, ipr,
             driftflux, esp, valve, annulus, well, sweep
src/ui/      UI: charts (canvas), main (панель параметров, вкладки, sweep)
src/data/    pumps.json — 43 насоса из БД unfpy
tests/       паритет с эталонами unfpy, sanity, решатель, стресс
```

Единицы: давление atma, температура °C, расходы ст. м3/сут, длина м, вязкость сП.
Стандартные условия 1 атма / 20 °C (как в unfpy).
